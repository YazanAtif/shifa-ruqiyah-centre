# Shifa-Ruqiyah Centre - Patient Management System

A web-based Patient Management and Appointment Scheduling System designed for **Shifa-Ruqiyah Centre**.

## Features

- **Admin Portal**: Intuitive administrative dashboard with 1-click quick action cards.
- **Patient Directory & Registration**: Comprehensive patient profiles with auto-generated IDs, international country/dialing code detection, and live age calculations.
- **Appointment Scheduling**: Complete session booking, status management (Pending, Confirmed, Completed, Cancelled), fee calculations, and multi-currency support (PKR / USD).
- **Spiritual Numerology Engine**: Pythagorean & Chaldean numerology profiles with bilingual (English & Urdu) insights.
- **WhatsApp Integration**: Instant formatted appointment notifications sent via direct `wa.me` links.
- **Printable Records**: Clean print layouts for appointment letters, session slips, and full patient history records.
- **Offline-First & Backup**: Powered by browser LocalStorage with one-click JSON backup export and restore capabilities.

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript (Single Page Application)
- Responsive mobile & desktop layout
- Custom beige, brown, and cream aesthetic with smooth ambient background animations

## Deployment
Hosted live on VPS and deployed to Vercel.
